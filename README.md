# KBO Hidden Talent — 검증용 웹 프로토타입

`index.html`을 브라우저에서 열거나 GitHub Pages에 올리면 됩니다.

조건 목표: 2026년 기준 만 27세 이하, 국내 선수(타자+투수), STATIZ 통산 WAR 3.0 이하.

중요: 공개 검색만으로 전체 선수의 생년월일과 통산 WAR을 모두 대조하지 못했으므로 후보는 '검증 대기'로 표시합니다. 검증되지 않은 WAR 값을 만들지 않았고 조건 통과가 확정된 목록이라고 주장하지 않습니다.

출처:
- STATIZ https://www.statiz.co.kr/
- KBO 공식 기록실 https://www.koreabaseball.com/Record/Player/
- TVING KBO 기록 https://www.tving.com/sports/kbo/history
